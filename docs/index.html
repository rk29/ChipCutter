Offline 2.5D, 3-Axis, V-Carve, & 4th-Axis Desktop CAM

Turn 3D STEP solids, STL / OBJ / 3MF meshes, DXF / SVG vectors, and parametric 2D sketches into arc-accurate (G2/G3) and inverse-time 4-axis (G93) G-code—verified with heightmap and Tri-Dexel volumetric simulation before a single chip is cut.

Key Capabilities

Offline-first, open-source, and native on Linux, Windows, and macOS.

STEP B-Rep & Associative Reload

Imports ISO 10303 STEP solids with analytic plane, cylinder, cone, and arc classification, interactive 3D picking, non-destructive model transforms, and associative Ctrl+R revision re-matching.

2.5D Milling, Adaptive Rest, & Thread Milling

Facing, 2D Contour with holding tabs, multi-island Pockets, constant-engagement 2D Adaptive trochoidal clearing, preceding-operation Rest Machining, Drilling/Helical Boring, Edge Chamfering, and internal/external Helical Thread Milling (ISO Metric & UNC/UNF presets).

3-Axis Mesh Surfacing

High-precision 3-axis drop-cutter and push-cutter machining over STL, OBJ, and 3MF meshes for 3D Adaptive Roughing, 3D Waterline, Parallel Raster, Constant-Scallop, and Pencil Fillet Cleanup.

4th-Axis Rotary (A / B / C)

Supports 2-Linear + Rotary cylindrical wrapping (Z+X+A), continuous spiral surfacing, Indexed 3+1 multi-face milling, and Simultaneous 4-Axis (X+Y+Z+A) with G93 inverse-time feeds.

Heightmap & Tri-Dexel Simulation

Switch between fast 2.5D Heightmap and full 3D Tri-Dexel volumetric stock simulation with quantitative error volume, RMS/MAE/P95/P99 surface deviation metrics, Error Heatmap, and a mandatory 5-rule crash gate.

V-Carve, Pure-2D, & Machines

3D medial-axis V-carving with two-stage flat clearance and mated Male V-Inlays, DXF/SVG vector jobs, TrueType + Hershey typography, 7 built-in CNC machine profiles (Carvera, Milo, Voron Cascade, Generic), Fusion 360 tool import, and portable .chipz bundles.

Download & Install

Prebuilt desktop apps and headless CLI binaries are published with SHA-256 checksums on GitHub Releases.

Linux (Flatpak & CLI)

Sandboxed x86_64 desktop + CLI Flatpak bundle or standalone CLI tarball.

flatpak install --user ChipCutter-0.16.0-linux-x86_64.flatpak
flatpak run io.github.rk29.ChipCutter

Windows (x86_64)

Install via .msi (with .chip.toml/.chipz associations) or portable .zip.

# Run desktop GUI or headless CLI:
chip-gui.exe --sample rotary-4axis
chipcutter.exe --version

macOS (Universal2)

Native Apple Silicon & Intel .dmg app bundle (macOS 12+).

# Drag ChipCutter.app into Applications
# Optional CLI symlink:
ln -s /Applications/ChipCutter.app/Contents/MacOS/chipcutter /usr/local/bin/chipcutter

Looking to compile from source or contribute? See DEVELOPMENT.md on GitHub.

Safety & Alpha Notice: ChipCutter is alpha-quality personal open-source software. Always verify 0 Crashes in 3D simulation, inspect generated G-code, confirm physical G54 zero and workholding clearances, and perform an air-cut before machining.
