Turn 3D STEP solids, STL / OBJ / 3MF meshes, DXF / SVG vectors, and parametric 2D sketches into arc-accurate (G2/G3) and inverse-time 4-axis (G93) G-code—verified with heightmap and Tri-Dexel volumetric simulation before a single chip is cut.

Key Capabilities

Offline-first, open-source, and native on Linux, Windows, and macOS.

STEP B-Rep, Meshes, & Streamlined UX

Imports ISO 10303 STEP solids and watertight STL / OBJ / 3MF meshes with associative Ctrl+R revision re-matching, non-destructive model transforms, Active Setup top-bar operation creation, unified Settings (Ctrl+,), and guided machine-switch tool swapping.

2.5D Milling, Cutting Areas, & Thread Milling

Exact-polygon Facing, 2D Contour + Tabs (with stock clipping & open-chain extension), multi-island & boss-clearing Pockets, 2D Adaptive + Rest Machining, Engagement-Aware Feed Optimization, Drilling/Boring, and ISO Metric & UNC/UNF Helical Thread Milling—all with unified [Geometry] 3D boundary previews.

3D Workholding, Wizards, & Stock Carryover

Parametric vises, parallels, toe clamps, spoilboards, and imported fixtures with Auto-Avoid Rapids, Rule 6 FixtureCollision, multi-setup G54 → G55 Tri-Dexel stock carryover, Flip-Jig Dowel-Pin Wizard, and Auto Soft-Jaw Generator.

Undercuts & 3D Edge Deburring

Non-planar 3D B-Rep edge deburring (Deburr3D) with automatic FlatBvh inside-corner wall trimming, Lollipop underside back-chamfering, and [Geometry] XY boundary clipping, plus DIN 650 T-Slots, Blind Keyways, Internal/External 60° Dovetails, and Lollipop Undercut3D.

3-Axis Surfacing, 4th-Axis Rotary, & V-Carve

3-Axis Adaptive, Waterline, Parallel, Constant-Scallop, and Pencil cleanup with true projected Model Silhouette; 4th-Axis Wrapping (Z+X+A), Indexed 3+1, and Simultaneous X+Y+Z+A (G93) with -U/+U axial boundaries & chuck-guard previews; 3D medial-axis V-Carving + Male V-Inlays, DXF/SVG biarcs, and 7 built-in CNC machine profiles.

GPU Compute Simulation & Error Metrology

wgpu Compute backend powering zero-readback Heightmap, Cylindrical, and volumetric 3D Tri-Dexel simulation with crease-preserving CPU/GPU mesh skinning (Settings → Simulation), Activity Log execution timing, < 0.1 ms Error Heatmap, RMS/MAE/P95/P99 metrics, and a mandatory 6-rule crash gate.

Download & Install

Prebuilt desktop apps and headless CLI binaries are published with SHA-256 checksums on GitHub Releases.

Linux (Flatpak & CLI)

Sandboxed x86_64 desktop + CLI Flatpak bundle or standalone CLI tarball.

flatpak install --user ChipCutter-0.21.1-linux-x86_64.flatpak
flatpak run io.github.rk29.ChipCutter

Windows (x86_64)

Install via .msi (with .chip.toml/.chipz associations) or portable .zip.

# Run desktop GUI or headless CLI:
chip-gui.exe --sample rotary-4axis
chipcutter.exe --version

macOS (Universal2)

Native Apple Silicon & Intel .dmg app bundle (macOS 12+).

# Drag ChipCutter.app into Applications
# Optional CLI symlink:
ln -s /Applications/ChipCutter.app/Contents/MacOS/chipcutter /usr/local/bin/chipcutter

Looking to compile from source or contribute? See DEVELOPMENT.md on GitHub.

Safety & Alpha Notice: ChipCutter is alpha-quality personal open-source software. Always verify 0 Crashes in 3D simulation, inspect generated G-code, confirm physical G54 zero and workholding clearances, and perform an air-cut before machining.
